# Print request

Please quote one of each of the three case parts, in millimetres:

- `front-frame.stl`
- `internal-carrier.stl`
- `rear-cover.stl`

The alternative `all-parts.stl` contains these three parts and both clip
coupons in one file. The five parts are separate, with 10 mm gaps.
Use millimetres and 100% scale. Do not join the parts.

For Craftcloud, upload one part per file. Do not use `all-parts.stl`.
The `low-material/` directory contains an alternative with 25.7% less
material. Quote either the original set or the alternative set, not both.
The alternative carrier is a 1.5 mm screen rim with four clips. It has no
component mounts. Please review the thinner frame and cover panels.

Material: **unfilled PA12 nylon**, MJF preferred.
Finish: **vapour smoothing**, light grey if available.

These parts use reusable snap fits. Please review the **1.5 mm clip arms**,
**9 × 4 mm release slots**, **2.8 mm strap slots**, and **0.4 mm nominal mating
clearance** for this process and finish. Preserve the mating features and
openings. Do not print the parts as an integrated assembly.

The two optional clip coupons form one test pair. Please quote them with
the same material and finish. We use them to check the fit and release before
printing the full case.

Please report any feature that needs a change before manufacture. STEP files
are available for geometry review. The parts are a first fit prototype.
